# Earthquake-Damage-Detection

- In models folder -> add the checkpoints of the best models of each region (name it like chine_best.pt, mexico_best.pt, morocco_best.pt)
- app.py -> The main streamlit code
- model.py -> Replicates the model flow
- Inference folder -> Manages the prediction and overlay of predicted mask on post image
- Preprocessing folder -> Contains the codes for blur, brightness and registration correction
- Create and "Output" folder that stores the prediction results.
